대표 문제와 해설

실제 문제는 정답뿐 아니라 구분 근거까지 설명합니다

사이트에는 고조선·삼국부터 근현대까지 실제 출제 기준을 통과한 240개 이상의 자체 제작 고난도 문제가 있습니다. 아래 대표 문제로 문제 구성과 해설 방식을 먼저 확인한 뒤, 원하는 시대의 10문제 퀴즈를 시작해보세요.

통일신라

1. 다음 중 신문왕의 왕권 강화 정책으로 옳은 것은?

  1. 녹읍을 폐지하였다.
  2. 독서삼품과를 시행하였다.
  3. 청해진을 설치하였다.
  4. 후백제를 건국하였다.
정답과 해설 확인

정답은 1번입니다. 신문왕은 김흠돌의 난을 진압하고 관료전을 지급한 뒤 녹읍을 폐지해 귀족의 경제 기반을 약화했습니다. 독서삼품과는 원성왕, 청해진은 흥덕왕 때의 사실이며 후백제는 견훤이 세웠습니다.

고려

2. 노비안검법을 시행하고 쌍기의 건의를 받아 과거제를 도입한 왕은?

  1. 태조
  2. 광종
  3. 성종
  4. 공민왕
정답과 해설 확인

정답은 2번 광종입니다. 광종은 노비안검법으로 호족이 불법적으로 거느리던 노비를 양인으로 돌리고, 과거제를 통해 능력을 기준으로 관리를 선발하며 왕권을 강화했습니다.

조선

3. 공인이 등장하고 토산물 대신 쌀·옷감·동전 등으로 공물을 납부하게 한 제도는?

  1. 영정법
  2. 대동법
  3. 균역법
  4. 호포제
정답과 해설 확인

정답은 2번 대동법입니다. 대동법은 가호마다 부과하던 공물을 토지 결수에 따라 쌀·옷감·동전으로 거두게 했습니다. 공인이 관청에 필요한 물품을 조달하면서 상품 화폐 경제의 발달에도 영향을 주었습니다.

개항기

4. 다음 사건을 이른 순서대로 바르게 나열한 것은?

임오군란 · 갑신정변 · 동학 농민 운동 · 갑오개혁

정답과 해설 확인

임오군란(1882) → 갑신정변(1884) → 동학 농민 운동(1894) → 갑오개혁(1894) 순서입니다. 동학 농민 운동과 청·일 양국의 파병은 청일 전쟁과 갑오개혁이 전개되는 배경이 됐습니다.

일제강점기

5. 1920년 10월 김좌진의 북로군정서군 등이 일본군과 싸워 승리한 전투는?

  1. 봉오동 전투
  2. 청산리 대첩
  3. 자유시 참변
  4. 대전자령 전투
정답과 해설 확인

정답은 2번 청산리 대첩입니다. 봉오동 전투는 같은 해 6월 홍범도 부대 등이 거둔 승리이고, 청산리 대첩은 10월 김좌진·홍범도 부대 등이 백운평과 어랑촌 등에서 벌인 여러 전투를 묶어 부르는 말입니다.

한국사 10분 챌린지 활용법

문제를 풀고, 틀린 부분을 바로 복습하는 한국사 학습 흐름

한국사 10분 챌린지는 짧은 시간 안에 현재 실력을 확인하고, 틀린 문제를 다시 정리할 수 있도록 만든 무료 한국사 학습 사이트입니다. 고조선·삼국부터 통일신라와 발해, 고려, 조선, 근현대까지 시대별 문제를 풀 수 있으며, 전체 문제를 선택하면 여러 시대가 섞인 10문제 퀴즈로 실전 감각을 점검할 수 있습니다.

1. 10문제 퀴즈로 빠르게 점검

긴 시간을 들이지 않아도 하루 10분 정도면 주요 시대의 흐름과 자주 헷갈리는 개념을 확인할 수 있습니다. 문제를 풀면서 정답과 해설을 함께 보도록 구성해 단순 암기보다 이해 중심의 복습에 가깝게 사용할 수 있습니다.

2. 오답노트와 학습 분석으로 약점 확인

틀린 문제는 오답노트에 저장되어 나중에 다시 확인할 수 있습니다. 학습 분석에서는 시대별 정답률을 확인할 수 있어 조선 후기 제도, 고려 정치사, 근현대 독립운동처럼 자신이 약한 범위를 파악하는 데 도움이 됩니다.

3. 연표와 비교 정리로 개념 연결

문제를 풀다 보면 사건의 순서나 비슷한 제도 차이가 헷갈릴 수 있습니다. 이럴 때 핵심 연표로 흐름을 잡고, 비교 정리 페이지에서 갑오개혁·을미개혁·광무개혁, 훈구와 사림, 대동법·균역법·영정법 같은 주제를 따로 확인할 수 있습니다.

처음 방문했다면 전체 문제로 실력을 점검한 뒤, 오답노트와 학습 분석을 확인하고 약한 시대의 연표나 비교 정리로 이어서 복습해보세요.
